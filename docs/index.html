SFL Browser

Open-source, Community-built

About

SFL Browser is an open-source Android browser and notification companion for Sunflower Land. Play in the built-in browser or use the app just for farm and marketplace alerts.

Features

  • Full browser and Notifications only modes
  • Farm notifications and marketplace price alerts
  • Overview and Timeline for farm timers and game events
  • Built-in browser tabs, a customizable toolbar, and native color themes
  • Support for WalletConnect connections started by the game

Browser and notification modes

  • Choose Full browser or Notifications only when you first open the app. To change it later, open Settings → Browser.
  • In Notifications only mode, you can choose which app opens when you tap an alert.
  • Long-press the launcher icon for shortcuts to Overview, Timeline, and Settings.

How to set up notifications

  1. Allow Android notifications when prompted. Exact alarms and ignoring battery optimisation are optional and can be changed later in Settings.
  2. Open Settings → Farm & Sync in SFL Browser.
  3. Enter your Farm ID and API key. In Sunflower Land, open Settings → three-dot menu: your Farm ID is at the top, and your API key is under General → API Key.
  4. Tap Run a check now to verify the setup.

How to Install

  1. Get the app from Google Play if it is available to you.
  2. For direct APK downloads, see the assets listed on GitHub Releases.

For advanced users

The native Kotlin app builds from the repository root using JDK 17 and Android SDK 36. See the README build instructions for debug and release commands.

Safety

  • Never share your wallet recovery phrase with anyone. No legitimate app or developer will ever ask for it.

  • Only install the app from trusted sources, such as the official Google Play Store or this project's GitHub releases. Avoid downloading APKs or content from unknown or suspicious sites.

Privacy Policy

This policy describes how SFL Browser handles information when you browse, use farm and marketplace alerts, or choose to share crash reports.

Farm and marketplace alerts

If you set up farm sync, the app stores your Farm ID and encrypts your Sunflower Land API key using the Android Keystore. It sends the key to Sunflower Land's API when authenticating community requests and uses returned farm and market information to power alerts, Overview, and Timeline. Settings, alert rules, and recent results are stored on your device so those features can work between checks.

Browsing and wallets

In Full browser mode, the built-in Android browser loads the websites you open. Websites can use cookies or local storage and handle your activity under their own privacy policies. If you search from the address bar, the search is sent to Google.

If you connect a compatible wallet, the app uses WalletConnect (Reown) to relay connection and signing requests. Websites, wallets, or blockchain network providers may receive public wallet addresses and transaction information as part of those requests. Review requests in your wallet before approving them. The app does not ask for wallet recovery phrases or private keys.

When a website requests a wallet connection, the app's WalletConnect SDK sends a generated client ID to authenticate with Reown's relay and may send technical diagnostics, such as a pairing failure, to Reown. This can happen before you approve a connection in your wallet. These requests are separate from ordinary web browsing and are not controlled by the app's optional crash reporting setting. See Reown's privacy policy for more information.

Optional crash reporting

When you first open a version with crash reporting, the app asks if you want to share reports. Google Firebase Crashlytics starts only after you choose to allow reporting and restart the app. Declining does not limit any browser or notification features.

If you opt in, Google Firebase receives diagnostics over HTTPS to help the developer identify and fix crashes and, on supported Android versions, app freezes. This can include stack traces, exception messages, app version and state, Android version, device model, network connection type, installation identifiers, and session information such as when the app came to the foreground. The app does not use Google Analytics or attach browsing history, cookies, farm credentials, wallet details, or custom logs to these reports. Exception messages are generated by the app and its libraries and can contain details about the operation that failed. Ordinary errors that the app handles are not reported by this feature.

You can change your choice in Settings → Farm & Sync → Share crash reports. Changes take full effect after restarting the app. Turning reporting off does not delete reports already sent to Firebase. See Privacy and Security in Firebase for how Firebase handles diagnostic data. Use the contact address below for questions or requests about your diagnostic data. This setting does not control Android's separate diagnostics reporting to Google Play.

Android permissions and controls

Notification permission lets the app post alerts. Exact-alarm access and exemption from battery optimisation are optional and affect when alerts can be delivered. You can change these permissions in Android Settings.

You can remove your API key and Farm ID from Farm & Sync, or clear the app's local data through Android Settings. Clearing local app data does not delete information already held by a website, wallet provider, or other service.
